🚀 FFmpeg Power Tips

  • Fast Cuts: Use -ss before -i to seek quickly using keyframes.
  • Stream Copy: -c copy skips encoding entirely, completing operations in sub-seconds.
  • Aspect Ratio: Using scale=-2:720 forces the width to automatically scale while keeping divisible-by-2 compatibility for H.264 codecs.
  • Hardware Acceleration: Add -hwaccel auto or -c:v h264_nvenc on NVIDIA RTX GPUs for 5x encoding speed!
